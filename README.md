# 💰 Expense Tracker

A full-stack **expense tracking web application** that helps users manage daily spending with authentication, multi-currency support, analytics dashboards, and AI-powered insights.

The app provides an intuitive interface to track expenses, analyze spending patterns, and make better financial decisions.

---

## 🌐 Live Demo

https://expense-tracker-five-kohl-12.vercel.app/

---

## 🚀 Features

* 🔐 **User Authentication** (JWT-based login & registration)
* 💸 **Expense Management** – add, edit, and delete expenses
* 💱 **Multi-Currency Support** with automatic conversion
* 📊 **Interactive Dashboard** showing weekly, monthly, and yearly summaries
* 📈 **Visual Reports** with category breakdown and monthly trends
* 🤖 **AI-powered Expense Insights**
* 📥 **CSV Export** for external analysis
* 🌓 **Dark / Light Mode**
* 📱 **Responsive Design** for mobile and desktop

## ⚙️ Setup

Install dependencies

```bash
npm install
```

Create `.env` file

```
PORT=5000
MONGODB_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key

EMAIL=your_email
EMAIL_PASS=your_app_password

GEMINI_API_KEY=your_gemini_api_key
```

Start the server

```bash
npm start
```

Open in browser

```
http://localhost:5000
```
